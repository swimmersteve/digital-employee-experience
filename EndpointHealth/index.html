How health is determined

A machine is Healthy when, in the evaluation window, neither of these fired:

  • A breached threshold — High CPU, Low CPU clock speeds, Low memory or High disk activity, from Microsoft-Windows-Diagnosis-PLA/Operational, sorted by which counter the alert message names. Windows owns the thresholds; this page reports that an alert fired, not what the number was.
  • An application crash or hang — Application Error (event 1000) or Application Hang (event 1002).
  • A system crash — an unexpected shutdown (Kernel-Power 41, EventLog 6008) or a bugcheck (1001 from the system-error-reporting provider).

Uptime and the Windows Reliability score sit under System health for context but do not drive the badge. Reliability is Reliability Monitor's System Stability Index (0–10), a trailing daily figure — it says nothing about the last few minutes, which is why only crashes colour that section's chip.
